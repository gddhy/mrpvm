## MRP 模拟器: 程序退出弹窗功能

### 需求
index.html 的 `window.onerror` 中添加弹窗: 用户退出网页内 mrp 程序或 mrp 正常/异常退出时,
弹出「Mrp程序已退出」提示, 含两个按钮:
- **打开应用列表**: 重新打开模拟器网页, 运行默认 dsm_gm.mrp 列表程序
- **重新运行当前Mrp**: 仅在检测到外部 mrp 时显示 (通过 `?f=xxx.mrp` URL 参数 或 PWA launchQueue 传入)

### 实现
- **index.html**:
  - 新增 `#mrpExitDialog` 弹窗 HTML (复用 confirm-overlay 样式, 位于 confirmDialog 之后)
  - 新增 `showMrpExitDialog()` / `vmrpOpenAppList()` / `vmrpRerunCurrentMrp()` 函数
    - `showMrpExitDialog`: 检测 `GetQueryString('f')` 或 `window.vmrpRelaunchSaved` (fs.js 设置),
      决定是否显示「重新运行当前Mrp」按钮; 显示当前程序文件名
    - `vmrpOpenAppList`: 清除 sessionStorage `vmrp_launch_file`, 设置 `vmrp_skip_launch_wait`=1,
      跳转 `pathname + hash` (去掉查询参数)
    - `vmrpRerunCurrentMrp`: `window.location.reload()` (?f= 场景 URL 自带参数; launchQueue 场景由 fs.js 从 sessionStorage 恢复)
  - 重写 `window.onerror`: 用 `#main.loaded` 判断模拟器是否已启动, 已启动则弹窗,
    未启动保持原「模拟器异常, 请刷新网页」逻辑; 之后照旧替换 Module.setStatus

- **fs.js**:
  - 新增外部 mrp 状态: `window.vmrpExternalRun` / `window.vmrpLaunchFileName` / `window.vmrpRelaunchSaved`
  - `?f=` 场景在 runWithFS 中设置 vmrpExternalRun=true
  - launchQueue 场景: consumer 收到文件时写入 dsm_gm.mrp 并 `saveRelaunchFile(lf)` (base64 存 sessionStorage `vmrp_launch_file`);
    本次启动无文件时 `clearRelaunchFile()`
  - 重载恢复: loadFileAsync dsm_gm 分支中, `isPageReload`(performance navigation type) 或 `skipLaunchWait`
    标记时跳过等待 launchQueue, 直接 `getRelaunchFile()` 从 sessionStorage 恢复外部 mrp 自动运行
  - base64 辅助: arrayToBase64/base64ToArray (分块 fromCharCode, 防大文件调用栈溢出)

### 关键机制 (退出如何到达 window.onerror)
- Emscripten `exit()` → `quit_(status, new ExitStatus(status))` → throw
- MRP 程序由事件驱动调用 exit (非 callMain 内), ExitStatus 异常直达 window.onerror
- `abort()` 抛 WebAssembly.RuntimeError 同样到达
- callMain 内正常 exit 会被捕获不触发 (unwind/ExitStatus 已被 callMain 处理)

### 追加: 修复 "mrp 点击退出不弹窗" bug (核心机制!)
- 现象: 日志显示 mr_exit()/mr_close()/mythroad exit. 但退出弹窗不弹出
- 根因: MRP 主循环内 exit() 抛 ExitStatus, 被 vmrp.js 的 Browser.mainLoop.runIter 的
  catch(e instanceof ExitStatus){return} 静默吞掉, 到不了 window.onerror;
  且 setMainLoop 设 noExitRuntime=true → exit() 跳过 Module.onExit 分支, onExit 钩子无效
- 修复:
  1. vmrp.js runIter catch 分支: ExitStatus 捕获处插入
     if(Module["onMrpExit"])Module["onMrpExit"](EXITSTATUS)  (单点补丁, 向后兼容)
  2. index.html Module 定义新增 onMrpExit 钩子 → showMrpExitDialog()
- 覆盖情况: 主循环内正常/异常 exit → onMrpExit 弹窗; abort 崩溃 → RuntimeError 仍走
  window.onerror; unwind/普通异常行为不变; 未定义钩子时行为不变
- 验证: 10 用例 + 端到端联动 (ExitStatus→onMrpExit→弹窗显示) 全部 PASS
- 注意: vmrp.js 是 Emscripten 构建产物, 本次为手改补丁 (项目直接维护该文件)
